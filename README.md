# Clip Review

A phone app for reviewing Apex Legends clips. You go through each clip one pass at a time, log what went wrong, and see which mistakes keep coming back.

Install: open the site in Chrome on Android, then menu → **Install app** (or **Add to Home screen**).

Your reviews are stored only on your phone, in the browser's storage for this site. This repository holds the app's code and none of your data. Use **Log → Save backup file** to keep a copy of your reviews.
